## Overview

Mentality v1.2.2 is a stable Windows maintenance release focused on hotkey registration and Windows-key modifier support.

## Fixes

- Fixed broken hotkey registers.
- Fixed MOD_WIN support issues.
- Miscellaneous bug fixes.

### Hotkey registration

This release addresses broken hotkey registration. This is a separate documented fix from v1.2.1, which addressed the hotkey setting doing nothing.

### Windows-key modifier support

Fixed support issues involving `MOD_WIN`, the Windows-key modifier used in hotkey combinations. Windows-key support was previously listed in v1.1.1; v1.2.2 adds fixes for that support rather than introducing it for the first time.

### Other maintenance fixes

Additional miscellaneous bug fixes are included. Individual issues and technical details have not been supplied.
